# مصنع المدونة — 12 وكيل AI يبنون مدونة ويديرونها بلا تدخل

منظومة كاملة تكتب وتنشر وتُحسّن مدونة ربحية تلقائياً، وتعمل **مجاناً** على GitHub.

---

## 1) القرارات المتخذة ولماذا

| القرار | الاختيار | السبب |
|---|---|---|
| النيتش | أدوات الذكاء الاصطناعي للمبدعين والشركات الصغيرة | CPC مرتفع (برمجيات) + عمولات أفلييت متكررة 20–50% + يقوم على خبرتك الفعلية في الموشن والأتمتة، وهذا ما يمنح الموقع E-E-A-T الذي تفتقده مدونات AI المولّدة |
| اللغة | الإنجليزية، جمهور أمريكي | النقرة تساوي 5–20 ضعف العربية |
| المنصة | Astro + GitHub Pages | مجاني بالكامل، سرعة قصوى (Core Web Vitals)، تحكم كامل في السيو |
| المحرك | Python + GitHub Actions | مجاني (2000 دقيقة/شهر)، مستقل عن n8n حتى لا يتعارض مع منظومة اليوتيوب |
| التربح | أفلييت أولاً + أدسنس ثانياً | الأفلييت يبدأ من أول زيارة، الأدسنس يحتاج حجماً |
| التكلفة | ~12$ سنوياً (دومين) + ~5–15$ شهرياً (توكنات) | لا استضافة، لا اشتراكات أدوات |

> النيتش قابل للتبديل بالكامل من `config/niche.yaml` دون لمس أي كود.

|---|---|---|

| 6 | `a06_seo_optimizer` | العنوان والوصف والسلَق والوسوم + فحص بنيوي (يمنع النشر إن رسب) |
| 7 | `a07_monetizer` | يحقن روابط الأفلييت والإفصاح ووحدات الإعلان |
| 8 | `a08_illustrator` | غلاف SVG بهوية الموقع لكل مقال — مجاناً بلا أي API |

| 10 | `a10_internal_linker` | يعيد نسج الروابط الداخلية بعد كل نشر |

**المنسّق** `orchestrator.py` يشغّلهم بالترتيب ويتعامل مع الأعطال بلا توقف.

## 3) خطوات التشغيل (30–45 دقيقة، مرة واحدة)

### أ. الرفع على GitHub
```bash
cd ai-blog-factory
git init && git add -A && git commit -m "init: blog factory"
gh repo create ai-blog-factory --private --source=. --push
```

### ب. المفاتيح — Settings ← Secrets and variables ← Actions
| المفتاح | مطلوب؟ | من أين |
|---|---|---|
| `ANTHROPIC_API_KEY` | **نعم** | console.anthropic.com |
| `TAVILY_API_KEY` | **موصى به بشدة** | tavily.com (1000 بحث/شهر مجاناً) — بدونه لا يذكر المقال أي أرقام |
| `OPENAI_API_KEY` | لا | بديل |
| `GSC_ACCESS_TOKEN` | لاحقاً | للتحسين الأسبوعي |

### ج. تفعيل النشر
Settings ← Pages ← Source: **GitHub Actions**. ثم Settings ← Actions ← General ← Workflow permissions: **Read and write**.

### د. الهوية
عدّل `config/site.yaml`: الاسم، الدومين، الألوان. ثم `python scripts/sync_config.py`.

### هـ. أول تشغيل
Actions ← «نشر المحتوى اليومي» ← Run workflow. سينشر مقالين خلال ~5 دقائق.

## 4) الجدول الزمني للربح (واقعي)

| المرحلة | المدة | ما يحدث |
|---|---|---|
| بناء الأساس | أسبوع 1–4 | 50–60 مقالاً، لا زيارات تقريباً — طبيعي |
| بداية الفهرسة | أسبوع 4–10 | Google يبدأ الترتيب على الذيل الطويل |
| أول دخل أفلييت | شهر 3–5 | 50–300$ شهرياً |
| قبول أدسنس | شهر 4–6 | يحتاج ~40 مقالاً وزيارات حقيقية |
| نضج | شهر 8–12 | 500–2000$ شهرياً إن استمر النشر |

> أي شخص يعدك بربح في الشهر الأول يبيعك وهماً. المدونة أصل يُبنى، لا زر يُضغط.

## 5) ما يحتاج قراراً منك لاحقاً
1. **الدومين** — سجّل اسماً قصيراً (Namecheap/Cloudflare ~12$/سنة) واربطه بـ Pages.
2. **برامج الأفلييت** — سجّل في البرامج وضع الروابط في `config/affiliates.yaml`.
3. **Search Console** — أضف الموقع وارفع خريطة `/sitemap-index.xml`.

## 6) الأوامر
```bash
python orchestrator.py daily      # التشغيل اليومي الكامل
python orchestrator.py scout      # توليد كلمات مفتاحية فقط
python orchestrator.py publish    # نشر ما في الطابور
python orchestrator.py optimize   # الصيانة الأسبوعية
cd site && npm run dev            # معاينة محلية
```

## 7) لماذا لن تُعاقب من Google
سياسة Google تعاقب **المحتوى المصنوع لمحركات البحث بلا قيمة**، لا المحتوى المُنتج بالـ AI. الحمايات المدمجة هنا: مصادر إلزامية لكل رقم، مدقّق يحذف الادعاءات المطلقة، عيوب حقيقية في كل مراجعة، منع النشر عند رسوب فحص السيو، وصفحات About/Contact/Privacy/Disclosure كاملة.
